# Datasets-related-questions
Data Analysis & Python Projects
This repository contains various Python scripts showcasing problem-solving, data analysis, and automation techniques. Below are some of the key projects included:

📌 Projects
1️⃣ Square Properties Calculator (problem1.py)
Generates a dictionary containing area and perimeter for squares of side lengths from 1 to a given number.
Uses dictionary comprehension for efficient computation.
2️⃣ Fruit Combination Generator (problem3.py)
Generates all possible combinations of fruits, weights, prices, and regions.
Saves the data in a CSV file (fruit_combination.csv) for further analysis.
Uses the itertools library for combinatorial processing.
3️⃣ Stock Market Data Analysis (problem4.py)
Fetches instrument data from the Kite API.
Filters for FINNIFTY options with a specific expiry date.
Computes the average strike price for the filtered instruments.
4️⃣ Sales Data Analysis (problem7.py)
Creates a sales dataset containing products, prices, and dates.
Computes total sales for each product and finds the highest-selling product.
Filters out products with quantity greater than 10 for better insights.
Uses pandas for data manipulation.
